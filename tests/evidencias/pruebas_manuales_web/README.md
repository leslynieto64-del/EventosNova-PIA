# Evidencias de las pruebas manuales de la interfaz web

Guía: `docs/GUIA_PRUEBAS_MANUALES_INTERFAZ_EVENTOS_NOVA.md`. Datos de prueba: `datos_controlados.json` (identificadores, sin contraseñas).

- `administrador/`, `coordinador/`, `proveedor/`, `transversal/`: una subcarpeta por módulo. Guarda ahí **tus** capturas con el nombre de la columna «Evidencia» de la guía (por ejemplo `A-04_pago_verificado_M03.png`).
- `_automaticas/`: capturas tomadas por los guiones automáticos de Chrome (prefijo `auto_`). **No son evidencia de la prueba manual**; solo muestran el estado de la interfaz cuando se verificó de forma automática.
- No guardes contraseñas ni datos reales en capturas.
- Una prueba solo se marca «Aprobada» en la guía si la ejecutaste y existe su captura.
